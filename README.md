# E-Commerce Sales Analysis – SQL Project

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data using MySQL.

The objective is to analyze sales, customers, products, returns, delivery performance, and profitability using SQL queries.

## 🛠️ Tools & Technologies

* MySQL
* MySQL Workbench
* SQL

## 📊 Dataset

The dataset contains information about:

* Order ID
* Customer ID
* Product ID
* Category
* Price
* Discount
* Quantity
* Payment Method
* Order Date
* Delivery Time
* Region
* Returned
* Total Amount
* Shipping Cost
* Profit Margin
* Customer Age
* Customer Gender

## 🔍 Key Analysis

The project includes analysis of:

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Average Order Value
* Category-wise Sales
* Region-wise Sales
* Monthly Sales
* Payment Method Analysis
* Return Rate
* Delivery Performance
* Top Customers
* Top Products
* Customer Age Group Analysis
* Ranking using Window Functions
* Month-over-Month Sales Analysis
* Running Total
